## Como Visualizar os Diagramas UML

Os diagramas estão em formato PlantUML (.puml). Para visualizar:

1. **Online:** Acesse http://www.plantuml.com/plantuml/uml/ e cole o conteúdo do arquivo
2. **VS Code:** Instale a extensão "PlantUML"
3. **IntelliJ IDEA:** Instale o plugin "PlantUML integration"
4. **Standalone:** Baixe PlantUML em http://plantuml.com/download
